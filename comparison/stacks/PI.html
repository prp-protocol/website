PRP over IP — selected stack

IPv4 / UDP / PRP wire-v4, protected adjacency and E2E 0x0202; numeric peers, known identities; privacy mechanisms enabled; independent deployment uses private IPv4; C08: interior transit between intermediaries, no endpoint rendezvous/deeper-session termination or optional traffic-history logging G01 global deployment: conventional globally routed IPv4/UDP over the BGP Internet, matching IP/MQ and round119 BP/LP/I2/GN. Private IPv4 deployments remain separate S03 capabilities; adjacent-only IP meshes are not this global witness. This does not change native PRP L3. F29–F31 architectural witnesses (round465): content-representing ALIAS for supplier discovery; digest-bound ALIAS with independently trusted expected reference for object verification; author-confirmed negotiated content custody serving additional consumers, including multicast announcement with custody. Content convention and consumer verification are explicit; no new core wire field, registered content namespace or completed custody-wire implementation is implied. Custody clarification (round467): E2E and multicast channel custody only, subject to negotiated responsibility and channel authorization; no public CDN-style object repository. F31 reuse is confined to authorized multicast consumers/branches. ALIAS possession does not grant access, and E2E retention for one recipient alone does not qualify as cross-requester reuse. C06 criterion-specific architectural witness: author-approved TPA successor fast paths (TPA candidate section 7; observer/bootstrap proposal section 10), established protected channels, distinct adjacency/final-channel identities and hop-local realization selectors. This replaces retained wire-v4 onion framing only for C06; no implementation or bootstrap admission is claimed. Other criterion profiles are unchanged. F32 architectural witness: author-confirmed local trajectory planning from future availability and usable capacity negotiated by each client with aggregators up to the rendezvous; each side negotiates its own half, including QoS/bandwidth reservation. Documentary architectural credit, not a completed wire/planner or global delivery guarantee.

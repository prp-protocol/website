GNUnet / CADET — selected stack

IPv4 / UDP TRANSPORT plugin / CORE / CADET; R5N discovery. GNUnet v0.20.x handbook is the explicit documentary baseline, not a claim about the latest release. Numeric private-IP neighbors, locally supplied HELLO contacts and known peer public keys; no online hostlist, DNS, NAT helper, GNS, file-sharing or Messenger service. Runtime version and discovery/bootstrap configuration remain to be qualified. G01 global deployment: conventional BGP-routed IPv4 Internet underlay, matching the IP/MQ global case; private deployments remain separate S03 capabilities. C08 witness: GNUnet 0.20.0 legacy UDP, proportional ATS, heap dhtcache with DISABLE_BF_RC=YES, peerinfo NO_IO=YES, logging NONE without forced overrides; fresh service state, no optional traffic archive/TNG, bootstrap contacts supplied again after restart. F16 witness: dedicated CADET endpoint with no local listening ports; locally initiated bidirectional channels only to an administratively selected set of peer public keys. Revocation uses a completed cold restart of the local CADET service and its consuming clients, discarding old channel/IPC delivery state before recreating channels only to the updated set. No application payload validator, external firewall or incoming-channel acceptance callback is credited. This is a controlled receiver/subscriber configuration, not an incoming server allowlist or uninterrupted hot revocation.

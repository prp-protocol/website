L02-LP: Yes

Rationale

The official py-libp2p implementation at the pinned commit declares MIT AND Apache-2.0 in pyproject.toml and includes a LICENSE-APACHE notice attributed to Zixuan Zhang. Its QUIC transport implements RFC 9000 configuration and integrates the libp2p private key and Peer ID with TLS security. Apache-2.0 section 3 supplies an express royalty-free contributor patent grant within the licensed Work. This additional implementation-bound witness meets L02 without treating the MIT-only go-libp2p license as an express patent grant.

Assessment method

Express patent-clause applicability review; no new runtime or legal clearance

Source context

Official pinned py-libp2p license, package metadata and native QUIC source; reviewed 2026-10-17

Outstanding qualification

The package metadata says AND, not OR: preserve both license obligations rather than inventing a choice. Credit only contributor-controlled claims necessarily infringed by contributions alone or with this Work; patent-litigation termination applies. This is not a grant for go-libp2p, independent reimplementations, all protocol claims or third-party dependencies. The Python code is an additional documentary license witness, not a replacement for existing Go runtime evidence or proof of all selected migration and policy behavior. No profile, interoperability, performance or other-cell verdict changes.

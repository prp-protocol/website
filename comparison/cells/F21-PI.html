F21-PI: Yes

Rationale

Wire-v4 HS2 authenticates both endpoint identities. The endpoint API exposes a provenance-bearing peer descriptor: Strong ID, public key, relationship/session references and transcript binding, only for an open relationship with established session. Application I/O is attached to that relationship. This supports reusing the authenticated final-peer identity without an application login/token exchange; it supplies neither civil identity nor application permissions.

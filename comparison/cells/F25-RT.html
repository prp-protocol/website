F25-RT: Yes

Rationale

Reticulum 1.5.5 supports a configured serial witness with retained identity/IFAC credentials and an expired Link/path cache. The adjacent available peer hosts the known destination. Eight endpoint packets cover path request, path-response announce, Link request, Link proof, RTT confirmation, Link.identify, a 256-byte encrypted data packet and explicit delivery proof. Each is bounded by the 500-byte selected Link MTU, plus a configured 16-byte IFAC. Worst-case HDLC escaping and two flags cost at most 1,034 serial octets per packet: 8,272 total. Charging 8N1 start/stop bits and rounding upward per packet gives 10,344 byte-equivalents, below 65,536.

Assessment method

Constructive documentary endpoint budget

Source context

Pinned Reticulum 1.5.5 source and serial wire accounting

Outstanding qualification

Bounded documentary witness, not a measurement or a bound for a busy mesh. Use one serial interface at 115200 8N1, Link MTU 500 (disable link MTU discovery), IFAC 128 bits, empty announce application data, no unrelated announced destinations, no probe service or periodic application announcements. The path-response context does not require ordinary announce rebroadcast. Retain provisioned keys and authorization; perform a fresh Link and identify before data acceptance. Deliver promptly before retry/keepalive timers; no claims about CPU time or energy. No Resource/LXMF transfer is added. This does not settle global announce volume, F15 or G05.

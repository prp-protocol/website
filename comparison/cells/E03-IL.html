E03-IL: Pending

Rationale

The official FreeBSD 14.3 ILNP v1.2.0 distribution is now downloadable: 80,944,353 bytes, SHA-256 6452ab440f9c9562cc3e024e56cf1ad79a4c7964af06b9c436e0ebd1da489c9e. Its 888 archive members include the modified libc and kernel binaries, configuration, shell tests and retained packet captures/transcripts. The installation document explicitly describes NID/L64 DNS support in libc, and the included May 2026 test transcript records getaddrinfo producing locator/identifier combinations. This removes the earlier download-access obstacle and supplies a concrete binary candidate. It does not supply the modified libc/kernel sources: there are no C, header, patch or diff members in this distribution. The earlier pinned public repository inspection therefore remains distinct from this later DNS-capable binary release. The author documents QTYPE=ANY interoperability limitations and ongoing locator-update work; those are not evidence that source cannot exist elsewhere.

Assessment method

Complete archive inventory and documentary review; no execution

Source context

Official ILNP binary release, installation document and included DNS test transcript

Outstanding qualification

Locate the public, appropriately licensed source corresponding to the DNS-enabled libc and kernel in this release, or another complete selected-profile implementation. Public binaries, author-provided test transcripts and existing FreeBSD source licenses do not establish public availability of these changes. No test was executed here, no supplied binary installed, and no global absence or No verdict inferred. E03-IL remains Pending. This finding does not alter D01 or other ILNP scores; installation and capture privileges are separate from ordinary application privileges.

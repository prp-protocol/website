E05-AX: Yes

Rationale

NCPACKET operator news records working radio links on 27 March 2017 and 12 January 2018, with intervening operational updates: a 291-day interval exceeding six months. This is a community-operated social communication network, not solely a research demonstration. The TARPN command documentation supplies a concrete profile mapping: radio-port NET/ROM circuit traffic between TADD and FIN carries conversation, while NODES/ROUTES documentation describes routing announcements. Installation instructions identify G8BPQ software by John Wiseman, distinct from the local node operators. Independence is credited to the user/operator community relative to the AX.25/NET/ROM protocol and node implementation authors; TARPN integration and hardware contributions are disclosed, not treated as a second independent implementation.

Assessment method

Historical operator evidence and explicit profile mapping; no new operational experiment

Source context

Dated NCPACKET operator history and TARPN NET/ROM trace, routing and installation documentation

Outstanding qualification

Documentary adoption finding for the historical direct-radio AX.25/NET/ROM role. The dated network history, protocol trace and configuration documentation are complementary evidence, not synchronized captures of every node. Exact binaries and uninterrupted availability are not attested. Later IL2P links are not substituted for the selected AX.25 binding. Local management interfaces and chat applications are outside the credited inter-node stack; no IP tunnel, mailbox semantics, encryption, radio-licensing exemption or modern full-profile runtime qualification is inferred. No radio transmission or private service access was performed.

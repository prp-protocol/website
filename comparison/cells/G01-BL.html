G01-BL: Yes

Rationale

An explicit provisioned hierarchy resolves the previously missing all-role inventory. Partition one locally assigned ULA /48 recursively into binary subdomains. Each router maintains a local discard route for its own aggregate and redistributes only that aggregate upward; it learns only its immediate child aggregates and the root /48 from its parent. It advertises only the root /48 downward. Exact-prefix/interface filters prevent leaf specifics from propagating globally. Leaf connected LAN routes override the local discard aggregate. For a reachable destination outside the local subtree, the root /48 takes traffic upward; at the lowest containing ancestor, more-specific child routes take it downward to the leaf. Every transit role, including the root, stores only local partitions, not the complete catalog of independently originated remote subdomains or leaf LANs. Babel source/feasibility records likewise cover only accepted parent/child origins under these filters; neighbor, local redistribution and temporary withdrawal state remain bounded by local degree for the fixed topology. A withdrawn child route first has unreachable hold state, then falls into the local discard aggregate rather than back toward the parent. Native prefix/interface filters and static-route redistribution support this construction without a new overlay or control service. It requires coordinated hierarchical addressing and topology; it does not establish ordinary Internet/BGP replacement, efficient operation at ten billion devices, multihoming or uninterrupted reachability during partition.

Assessment method

Constructive routing/state proof with native Babel filtering and redistribution; symbolic LPM checks, no Babel daemon execution

Source context

RFC 8966 filtering/hold behavior and babeld 1.13 native prefix/interface filters and route redistribution

Outstanding qualification

Run the generated per-role configurations with a pinned Babel daemon and real kernel routing in an isolated topology. Confirm import/advertisement of non-default static discard aggregates, exact filters, selected/fallback/source tables, unreachable hold and recovery. The executed model tests only converged LPM states; it does not emulate Babel sequence numbers, timers, reconvergence or kernel installation. No daemon, network or capacity experiment ran.

F14-GN: No

Rationale

The selected TRANSPORT/CORE/CADET/R5N stack protects end-to-end payload confidentiality and authenticates peers, but provides no selected endpoint-location-hiding mechanism. In GNUnet 0.20.0, ConnectionCreate carries the full ordered peer-identity path from origin to destination; forwarding peers process it after adjacent CORE decryption. Thus encrypted payloads do not hide the endpoint identity position in that overlay path. This does not assert that every relay learns the endpoint physical address or geographic location. Anonymous file sharing and other GNUnet subsystems are not part of this composition, and their goals are not inherited by CADET.

Assessment method

Versioned architecture and pinned GNUnet 0.20.0 connection-format analysis

Source context

CADET confidentiality scope and ConnectionCreate path format

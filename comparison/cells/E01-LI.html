E01-LI: Yes

Rationale

The official IETF 76 report records successful Cisco NX-OS/OpenLISP data-plane interoperability after fixes, and Cisco/LISP-Click IPv4 data-plane interoperability. OpenLISP is a separately developed UC Louvain FreeBSD implementation. Credit is restricted to historical basic IP-over-UDP/LISP packet exchange, common to this column, under the same bounded-function rule already used for E01-IP and E01-BP.

Assessment method

Primary interoperability report and protocol-lineage review; no execution

Source context

Margaret Wasserman, IETF 76 interoperability report (2009), slides 2–5; OpenLISP implementation report

Outstanding qualification

Historical draft-05 testing, not a new RFC 9300/9301 conformance test. The report identifies NX-OS and FreeBSD 7.x but does not pin exact binary builds or provide packet captures. Only the base encapsulated-data function is credited; no current Map-Register authentication, full control plane, application-UDP workload, LISP-SEC, or complete deployment qualification. Some pairs failed and some successes required fixes; no all-pairs claim. Shared standards participation does not imply shared implementation code. No tests were rerun.

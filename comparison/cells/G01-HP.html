G01-HP: No

Rationale

The global witness selects IPv6 with BGP/MP-BGP prefix routing. For the global case, explicitly select conventional BGP-routed IPv4/IPv6, using the same convention as IP, PRP-over-IP and Multipath QUIC. HIP decouples host identity from locators but still sends to IP locators. Its identity and mobility mechanisms do not replace the global prefix reachability infrastructure of this selected underlay. Endpoint default routes relocate that responsibility upstream.

Assessment method

Documentary composition and evidence reconciliation; no new runtime execution

Source context

Primary RFCs, explicit deployment convention and retained local experiment receipts

Outstanding qualification

This is a whole-stack verdict for the declared global Internet deployment, not a claim that HIP requires a global identity directory, that all routers hold full tables or that every possible IP topology needs BGP. Private operation and S03/S04 remain unchanged. No G05 capacity or runtime conclusion follows.

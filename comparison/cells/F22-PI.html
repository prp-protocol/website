F22-PI: Yes

Rationale

The pinned wire-v4 discovery architecture permits a bounded candidate set under a shared weak alias. Exact discovery resolves authenticated local declarations and each selected result proves its own Strong ID. This supplies independently identified candidates without a common alias signing key or controller. Directional admission, local catalog policy and result limits still apply. This Yes uses the existing weak-alias path, not the successor canonical-text ALIAS wire admission or a claim of implementation completeness.

Assessment method

Architectural specification analysis; no execution

Source context

Pinned PRP discovery architecture §3 and exact discovery §8.1

Outstanding qualification

Declare the same weak alias from two independent principals in the selected wire-v4 configuration. Verify distinct bounded results and exact selected-principal authentication, revocation/staleness and policy limits. Do not substitute successor HS2 or SCIR ALIAS encodings. No runtime test performed.

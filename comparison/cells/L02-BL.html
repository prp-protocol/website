L02-BL: Yes

Rationale

BIRD v2.17.1 provides a new implementation-scoped licensing witness. Its README offers GPL version 2 or, at the recipient's option, any later version. Selecting GPLv3 invokes section 11's express royalty-free grant of each contributor's essential patent claims, within that contributor version. The pinned proto/babel/babel.c implements Babel routing and explicitly identifies RFC 8966 among supported standards. Its notices identify Toke Hoiland-Jorgensen, Ondrej Zajicek and CZ.NIC. This is a grant attached to relevant routing code, sufficient for L02's holder-bounded implementation route.

Assessment method

Primary pinned implementation licensing and source-scope review; no runtime or patent clearance

Source context

BIRD v2.17.1 README and proto/babel/babel.c; GNU GPLv3 sections 11 and 14

Outstanding qualification

The licensing witness is BIRD under the GPLv3 option, not a claim that GPLv2 alone contains the same express grant. The scope is covered contributor versions and controlled essential claims, subject to the license conditions. No grant from babeld or babel-rs authors is inferred, and no patent search, enforceability opinion, all-holder clearance or right to every independent reimplementation is established. BIRD is not substituted for the implementation used in other matrix experiments; no routing, interoperability or scale verdict changes.

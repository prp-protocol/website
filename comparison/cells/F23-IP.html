F23-IP: No

Rationale

The previous Yes gave the endpoint a BGP routing role and authority to advertise a retained prefix at provisioned peers. That is administrative routing-domain relocation and fails the corrected endpoint criterion. The selected IP/BGP composition does not provide an ordinary host with locator-independent continuity when it changes access and address. Executing BGP on the same machine does not confer authority for its advertisements to be accepted. Mobile IP or a migration-capable transport could change the result, but neither is selected in this column. Same-link movement hidden by another layer is not credited as an IP mobility mechanism.

Assessment method

Corrected endpoint-role criterion; primary specification review

Source context

RFC 4271: BGP routing role; RFC 5944: distinct mobility extension

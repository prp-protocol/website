C06-AX: Yes

Rationale

The private serial role permits independent locally configured node and user labels for separate contexts. NET/ROM bind keeps source_addr and user_addr distinct and can set a locally authorized user label; interface configuration supplies the node label. A witness must separate both user and source-node identifiers and the lower AX.25 source, not merely change the SSID of a shared callsign. Use independently provisioned peer contexts and no shared identifying mnemonic or payload metadata. There is no mandatory common master identifier in these fields. Plain labels remain visible; known attachment/timing are excluded by C06. This is not an amateur-radio pseudonymity claim or automatic identity rotation.

Assessment method

Pinned primary-source inspection and bounded configuration/topology inference; no execution

Source context

Linux v6.12 source; NET/ROM 1.3 manual where indicated

Outstanding qualification

Use two isolated serial peer contexts with different node, user and AX.25 source labels. Check connect frames, NODES announcements, mnemonics and payloads for reuse. Configure local UID/capability policy intentionally; changing only port, circuit number or SSID does not qualify. No runtime capture performed.

Rationale

The public integration-shadow job 1789054 in pipeline 427048 succeeded on 22 October 2026 at Arti commit c87b1abe87460871a9a94371ccd311ad53400481. Its pinned CI configuration runs tests/shadow/run and does not allow job failure. The matching Shadow configuration starts a C Tor onion service with an authorized_clients file and an Arti client with a persistent keystore. The articlient-onion-auth traffic generator targets that authenticated v3 onion address; the validator requires at least one successful transfer out of ten attempts and exits nonzero otherwise. This joins a recorded executed job to the exact cross-implementation test rather than inferring execution from a release announcement or merged test source. Arti is a separate native Rust implementation, not a wrapper around C Tor; common Tor Project stewardship does not negate implementation independence under E01.

Assessment method

Executed-job receipt bound to cross-implementation authenticated transfer assertion

Source context

Public Tor Project CI job metadata and matching immutable Arti test sources

Outstanding qualification

Bounded evidence of authenticated onion-service traffic exchange in Shadow, not a reliability, anonymity, security or production-network qualification. The authenticated case requires only 1/10 successful streams because of documented test issues; actual transfer counts were not retrieved. The trace API returned HTTP 401, so execution is supported by public job status plus pinned test/configuration logic, not a claim to have inspected raw run logs. C Tor is installed from the Tor Project Bookworm package repository by this job; its exact package build was not recovered and is not invented. Optional Conflux onion-service behavior is not tested or credited here. Both implementations share project stewardship: this is independently developed code, not an independent third-party evaluation. No local test was executed.

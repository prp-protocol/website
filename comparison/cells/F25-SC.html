F25-SC: Yes

Rationale

A same-AS SCION/UDP endpoint exchange fits the 64 KiB budget with fresh underlay neighbor discovery. The official Empty path has zero wire bytes and is valid inside an AS. Pinned v0.13.0 snet writer code derives the direct underlay next hop from the numeric destination when the local and remote IAs match. With IPv4 host addresses, the SCION header is 12 common + 24 address + 0 path bytes. Each 256-byte UDP payload therefore costs 366 Ethernet byte-times including both UDP headers, outer IPv4 and link overhead. Two directions plus a fresh ARP request/reply total 900 byte-times. No expiring inter-AS segment or transport session is reused.

Assessment method

Constructive same-AS documentary byte envelope; no new protocol execution

Source context

Versioned official SCION header specification and v0.13.0 packet construction, plus IPv4/ARP/Ethernet accounting

Outstanding qualification

Conditional intra-AS witness, not a bound for Internet-wide SCION, remote path retrieval or control-plane startup. Use two endpoints in one provisioned IPv4/Ethernet subnet, numeric addresses, retained local topology/IA/ports and valid trust, with local daemon/dispatcher access. Expire neighbor state; count both ARP frames. No loss, unrelated broadcasts, optional extensions, DHCP/DNS, VLAN, fragmentation or extra security layer. This column supplies no end-to-end TLS or cryptographic peer authentication; none is inferred from the small budget. Any cross-AS, remote-daemon, certificate-refresh or additional link-security configuration needs a separate inventory. The established F25 definition accepts one bounded configuration and does not require crossing AS boundaries. No packet capture, implementation certification or energy claim.

C04-ND: No

Rationale

For a reachable ordinary content service, an uncredentialed peer can send an unsigned Interest for a known available name and receive recognizable NDN Data, including a cache response. The selected plain Ethernet NFD profile adds no secret admission or camouflage to that path. A silent missing-name result and authenticated management commands do not protect this successful content probe. This is a mechanism decision, not a measured fingerprinting rate or a claim that every node answers every probe.

Assessment method

Pinned source and specification analysis; no execution

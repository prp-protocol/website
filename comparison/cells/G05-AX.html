G05-AX: No

Rationale

No for the selected Linux 6.12 classic NET/ROM with active netromd and direct KISS links. nr_node_get compares exact callsigns in a linked list; nr_route_frame drops a nonlocal packet when that exact destination has no route. There is no prefix/default-route fallback in this path. netromd transmits individual eligible node records and installs received records, rather than aggregating regional destinations or performing demand-driven global discovery. Full destination reachability therefore requires a near-global destination catalog at an access forwarder; adding regional forwarders does not partition that access catalog. For ten billion native destination nodes, the selected struct fields alone consume at least 340 GB with 32-bit pointers or 460 GB with 64-bit pointers, before list links, locks, references, alignment and neighbor objects. A complete NODES advertisement contains at least 210 GB of destination records per advertising port before framing. Exact linked-list lookup adds linear search work. These replicated-state/control costs obstruct the common contemporary regional deployment, independently of radio speed.

Assessment method

Selected-profile namespace and source-based resource bounds; no runtime experiment

Source context

Linux v6.12 nr_route.c and netrom.h; ax25-tools 0.0.10-rc5+git20230513+d3e6d4f netromr.c/netromt.c

Outstanding qualification

Architectural/source-based plausibility decision, not an allocation, latency or global throughput benchmark. Bounds count independently addressed native NET/ROM destination nodes, not application users behind a shared node. A BBS/proxy or another hierarchical network layer would change this selected end-to-end service. Quality/obsolescence filters can reduce the catalog by removing reachability; they are not aggregation or a lookup service for omitted destinations. No all-to-all simultaneous traffic is assumed: the missing-route path and proactive catalog are independent of the 1000 destinations/day working set. The common physical regional graph is unchanged. The 64-GB reference is not promoted to a universal hardware ceiling; widespread unpartitioned state and repeated advertisements underpin the decision. Local amateur-radio use remains outside this global-capacity finding.

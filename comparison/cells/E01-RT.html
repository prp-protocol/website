E01-RT: Pending

Rationale

Leviculum supplies a concrete independently developed Rust candidate and a public completed-test account. Its hop-counting document reports two passing interoperability cells with a real Python Reticulum 1.3.5 initiator on 2026-09-26, with the Rust test source published. However, that same account explicitly says no 1.5.x daemon is run by this test tree. It describes substantive 1.5.x proof-hop rebalancing differences and a deliberate compatibility rewrite. The selected matrix profile is Reticulum 1.5.5; this is a real historical test, not yet a test of that complete version boundary.

Assessment method

Public report/source review and AST comparison; no new interop execution

Source context

Pinned Leviculum completed-test account and explicit untested-version boundary; upstream versioned Link.py comparison

Outstanding qualification

Pending. Retained 1.3.5 and 1.5.5 Link.py sources have identical ASTs for handshake, prove, identify, encrypt and decrypt; this narrows common mechanisms but does not prove equivalent dispatch or transport behavior. validate_request/validate_proof and Transport integration must not be inferred from those equal methods. The public report itself leaves the 1.5.x interoperability half outstanding. Obtain a versioned 1.5.5 exchange, or a complete compatibility argument for a precisely limited tested function, including applicable IFAC/serial and routing conditions. Source tests are not treated as an executed editorial test, and Python-derived vectors alone do not establish two-stack traffic exchange.

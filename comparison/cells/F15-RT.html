F15-RT: Pending

Rationale

No measured minimum-service result is claimed. The experiment now has an explicit target: Serial interface, IFAC checks, announces and Link state. Use the selected serial/IFAC profile. Measure actual serial occupancy, pending link state and announce work; an IP-based interface is not equivalent. The common protocol fixes eight adversarial origins, traffic/context/churn caps, calibrated legitimate load, fixed delivery deadlines and resource budgets, and repeated baseline/attack/recovery measurements. It distinguishes uncredentialed, admitted-participant and transit pressure. A result qualifies only its declared deployment and bounded budget; missing calibration or substituted layers cannot close this cell. Six fresh-process native ingress fixtures now include valid 16-byte IFAC, native queues/workers, real identity/path learning and temporary cache. Paced and burst results distinguish immediate learned paths from held announces; held packets have already passed signature validation. A corrupted IFAC control is rejected. Input comes from an in-memory receive-only interface with socket creation forbidden, not a serial medium or full forwarding topology. Release/expiry, service under attack and scale capacity remain unqualified. Valid-IFAC synthetic traffic assumes interface authorization; it is not evidence that an outsider without the IFAC secret can reach this processing path. The next fixture observes the same 64-destination burst through native release scheduling without new arrivals, clock acceleration, forced release or changed timers. Its timeline distinguishes delayed eventual route learning from immediate loss. This single isolated run cannot establish loaded convergence, serial capacity or a service floor. The ingress held-announcement map is distinct from the capped outgoing announce queue; their limits and aging rules must not be conflated. A separate two-run 300-destination fixture reaches the native 256-entry hold limit; unretained destinations at that observation are not a proof of permanent unreachability. Three follow-up fixtures recover all 42 previously unretained destination path entries after native local explicit requests and supplied valid IFAC path responses; an unsolicited-response control remains blocked. Native outgoing requests are captured and decoded before replies are supplied. This establishes conditional local recovery, not discovery by a remote responder, multihop convergence or query capacity. Recursive request propagation has additional limits and is not exercised. Native request_path tests now distinguish local and recursive calls under a genuinely populated outgoing announce queue and its timer. Recursive calls emit nothing while gated, whereas a local nonrecursive call emits with that queue occupied. After drain, the remaining cap interval still gates recursion; a new call succeeds after the interval. The blocked function calls do not register pending requests or emit later by themselves in this observation. Higher-level retries and actual multihop discovery remain outside this fixture. Three independent RNS processes now demonstrate an actual native query from A through B to C, a native response generated at C, and encrypted SINGLE payload delivery A-B-C. A and B begin without the target path, and C does not proactively announce. Whole IFAC frames are passed unchanged through harness pipes with no direct A-C edge, shared routing state or fabricated response. This closes the previous functional remote-response gap for one tiny unloaded topology only; serial capacity, congestion, churn and global scaling remain unqualified. Nine additional fresh chains pass at enforced 2400, 9600 and 115200 bit/s. Native HDLC escaping and flags are accounted at ten bits per byte (8N1); whole IFAC frames are delivered only after their scheduled serialization finishes. This adds finite-rate functional discovery and encrypted delivery evidence, but uses unloaded software queues rather than physical UARTs. It does not qualify discovery capacity, congestion, churn, hardware budgets or global scale. A further bounded-queue experiment submits sixteen distinct destination requests in one burst over a 9600-bit/s chain, with three repetitions each at 256, 1024 and 8192 wire-byte queue capacities per direction. It separately records harness tail drops, emitted native frames, discovery coverage after twelve seconds and exact encrypted payload delivery during a subsequent eight-second phase. Caller retries are absent. Incomplete discovery at the observation deadline is not permanent unreachability, and queue capacity alone is not a model of native recursive-request admission. This remains a small synthetic workload, not a contemporary-hardware global-capacity qualification. All nine runs discovered one of sixteen destinations and delivered its payload. At 8192 bytes all sixteen requests reached B without laboratory drops, but only one native request was emitted toward C. Thus the observed coverage limit cannot be attributed solely to finite link buffers; exact native branch attribution and paced/retry recovery remain untested in this round.

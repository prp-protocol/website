L01-CJ: Yes

Rationale

The pinned cjdns doc/contributing.md explicitly licenses the contained documents under CC BY 4.0 unless otherwise noted and describes their import into cjdns/doc. Thus the documentation grant is distinct from the root GPLv3 code license. For the selected route-server component, the pinned README identifies cargo doc as its documentation path; cjdns-ann/src/lib.rs describes announcement headers, entities and signing, and the ann/core/hdr/snode manifests declare GPL-3.0-or-later. These grants permit use and implementation without commercial or field-of-use restrictions. Required IP/UDP/TCP/HTTP/WebSocket specification layers use IETF implementation permissions.

Assessment method

Documentary rights and component-scope review; no execution or legal clearance

Source context

Version-pinned cjdns documentation notice and route-server documentation/manifests, 2026-10-15

Outstanding qualification

Apply attribution, license links and change notices to CC material; meet GPL source/copyleft obligations for covered derivatives. The guide uses the historical label Unported but links to the official CC BY 4.0 license. Do not extend the grant to externally linked papers or infer proprietary relicensing. This rights finding does not close E03-CJ client/server composition qualification, establish interoperability, or resolve L02 patent commitments.

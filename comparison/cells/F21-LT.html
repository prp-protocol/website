F21-LT: Pending

Rationale

BPSec security-source identity can name the bundle origin or a waypoint. The declared final-pair keys constrain the intended source but do not by themselves establish which verified identity and coverage flags the application receives. Resolve the native API binding of authenticated primary source and payload; do not import the separate Secure DTN implementation witness.

Assessment method

Documentary review; no new runtime experiment

Source context

Primary specification and bounded profile inference

Outstanding qualification

Pin implementation/API and exact-origin policies; test primary-source substitution, invalid or absent BIB, payload substitution and restart. Credit only identity bound to the delivered item after verification.

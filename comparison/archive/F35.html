Network-function deployment without endpoint modification

The selected composition can introduce a stated routing, path-management, mobility or connectivity function through intermediate network equipment while existing communicating endpoints retain their protocol implementations and applications. Identify the added function, upgraded equipment and unchanged endpoint boundary. Ordinary attachment or address provisioning may be allowed and must be disclosed. A new endpoint agent, protocol stack or application library does not qualify for that deployment. Merely operating the existing network unchanged does not establish an added function.

Assessment method

Primary architectural or protocol evidence for the selected composition; distinguish capability from execution

Research action

Describe a concrete before/after deployment, the new network benefit, required intermediate upgrades and any endpoint configuration changes. Verify that both communicating endpoint implementations remain unchanged. Distinguish D01 privileges, D02 kernel modules and F23 endpoint-controlled mobility.
